# Image

This page is for developers who change or run the Docker image in a project generated from Scaffold. It covers what the image contains and how to build it and run a container on your machine.

## Dockerfile

The [`Dockerfile`](https://github.com/AlexSkrypnyk/scaffold/blob/main/Dockerfile) installs Bash on the `alpine:3` base image and sets `entrypoint.sh` as the entrypoint. The following block shows its instructions without the digest pin and the labels:

```dockerfile
FROM alpine:3

RUN apk add --no-cache bash

COPY entrypoint.sh /usr/local/bin/entrypoint.sh

ENTRYPOINT ["/usr/local/bin/entrypoint.sh"]
```

The full file pins `alpine:3` to a digest. It also sets the `org.opencontainers.image.authors` and `org.opencontainers.image.source` labels from the Open Container Initiative (OCI) conventions.

## Entrypoint

The [`entrypoint.sh`](https://github.com/AlexSkrypnyk/scaffold/blob/main/entrypoint.sh) script sets strict shell options with `set -euo pipefail` and prints a line with your project name, such as `acme-app is running`. It then runs the container's arguments as a command with `exec`. With no arguments, the script ends after that line, so the container exits.

## Build and run the image

To build and run the image, run these commands in your project root, with your image name in place of `yournamespace/yourproject`:

1. Build the image:

   ```bash
   # Build the image
   docker build -t yournamespace/yourproject .
   ```

2. Run a container from the image, with no arguments:

   ```bash
   # Run the container
   docker run --rm yournamespace/yourproject
   ```

   Confirm that the container prints `acme-app is running`, with your project name in place of `acme-app`, then exits.
