# Linting

[Hadolint](https://github.com/hadolint/hadolint) checks a `Dockerfile` for common mistakes and departures from Dockerfile best practices. Follow this page to lint your `Dockerfile` before you build an image.

## Usage

To lint the `Dockerfile`, install Hadolint and run the following command in your project root:

```bash
hadolint Dockerfile
```

The `Dockerfile` starts with a `# hadolint global ignore=DL3018` comment, so Hadolint skips rule `DL3018`. That rule requires pinned package versions in `apk add`.

The `test-docker.yml` workflow also runs Hadolint in CI, before it builds the image. See [Testing](testing).
