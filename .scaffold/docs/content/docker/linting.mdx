# Linting

Hadolint checks a `Dockerfile` for common mistakes and departures from Dockerfile best practices. This page is for developers who change the `Dockerfile` in a project generated from Scaffold. Follow it to lint the `Dockerfile` before you build an image.

## Check the Dockerfile

To check the `Dockerfile`:

1. Install [Hadolint](https://github.com/hadolint/hadolint).
2. In your project root, run the following command:

   ```bash
   hadolint Dockerfile
   ```

   Hadolint lists each problem with its line number and rule code.

The `test-docker.yml` workflow runs Hadolint on the `Dockerfile` in CI too. To let CI pass when Hadolint fails, see [Testing](testing).

## Hadolint settings

The `Dockerfile` starts with a `# hadolint global ignore=DL3018` comment, so Hadolint skips rule `DL3018` in the whole file. That rule requires pinned package versions in `apk add`.
