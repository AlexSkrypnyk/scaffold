# Introduction

Scaffold is a project template for Shell, PHP, NodeJS and Docker projects. Each new project starts with working example code, tests, linters and CI workflows. This page is for developers starting a project from Scaffold.

## Quick start

The `init.sh` script sets up your project. It replaces `yournamespace`, `yourproject`, `Your Name` and other strings with your own values, and keeps the features you choose.

To create a project with the one-line installer:

1. Open a terminal in a new **empty directory**.
2. Run the following command and answer the prompts:

   ```bash
   curl -fsSL https://getscaffold.dev/init.sh | bash
   ```

   The script downloads Scaffold into the directory and then prompts you for the project details. Confirm that it ends with `Initialization complete.`

3. Commit the result to a new git repository and push it.

For automation and AI agents, replace the command in step 2 with this non-interactive one:

```bash
curl -fsSL https://getscaffold.dev/init.sh | \
  bash -s -- --namespace=AcmeApp --name=acme-app --author="Jane Doe"
```

The non-interactive command needs `--namespace`, `--name` and `--author`. The script uses the default for every other choice. With either command, the script downloads the latest release. To pin a tag, branch or commit, add `--ref` to the non-interactive command, for example `--ref=1.2.3`. Leave `--ref` out of the interactive command, because any option turns off the prompts.

### Alternative: start from a downloaded release

To start from a local copy instead:

1. Download the latest release from [GitHub](https://github.com/AlexSkrypnyk/scaffold/releases/latest).
2. Extract the archive and open a terminal in its directory.
3. Run `./init.sh` and answer the prompts.
4. Commit the result to a new git repository and push it.

Run `./init.sh --help` for all options.
