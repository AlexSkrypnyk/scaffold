# Library

In library mode, `init.sh` sets up a Composer package that ships classes and no executable. Use it for a Behat context, a PHPUnit extension, a framework plugin or a PSR implementation. `init.sh` keeps the PHP tooling and drops both entry points: the [CLI command](./php-command.mdx) app and the [CLI script](./php-script.mdx).

This page is for developers building a library from Scaffold. It covers how to select the mode, what it generates and how to replace the placeholder class.

To select library mode, decline both entry points:

```bash
./init.sh --namespace=AcmeApp --name=acme-app --author="Jane Doe" \
  --php --no-php-command --no-php-script
```

Replace the namespace, name and author with your own. Interactively, answer "n" to both `Use CLI command app` and `Use simple script`.

## What you get

`init.sh` generates the following:

- `composer.json` with the PSR-4 autoloader and no `bin` section
- `src/Example.php` and `tests/phpunit/Unit/ExampleUnitTest.php`, a placeholder class and its test
- PHP_CodeSniffer and PHPStan, configured to check `src` and `tests/phpunit`
- Rector, configured to check every PHP file outside `vendor` and `node_modules`
- PHPUnit, configured to report coverage of `src`
- The `Test PHP` GitHub Actions workflow

`init.sh` leaves out `php-command`, `php-script`, `box.json` and the PHAR build. It also leaves out the `Release PHP` workflow, because that workflow exists to attach a build to each tagged release.

With Renovate enabled (`--renovate`, the default), `init.sh` excludes `require` in `composer.json` from Renovate updates. Those constraints are your package's public contract, so you change them by hand.

## Add your classes

The `Example` class and its test are placeholders for your library's own code. Add your first class before you delete them, because PHP_CodeSniffer and PHPStan both report an error when the project holds no PHP file.

To replace the placeholder pair with your classes:

1. Add your classes under `src/`, in the `AcmeApp\App\` namespace. `AcmeApp` is your `--namespace` value.
2. Cover each class with a test in `tests/phpunit/Unit/`. Give each test class a `#[CoversClass]` attribute, because the run fails when a test has no coverage metadata.
3. Delete `src/Example.php` and `tests/phpunit/Unit/ExampleUnitTest.php`.
4. Run the tests:

   ```bash
   composer test
   ```

   Confirm that every test passes.
