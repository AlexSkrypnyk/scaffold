# PHP

PHP is on by default in `install.sh`, which sets up your project as a Composer package with PHP linting and tests. Start here to pick a PHP mode and find its tooling.

`install.sh` keeps 1 of 3 PHP modes and deletes the files of the other 2. Pick the mode that matches what you build:

| Mode | What you build | `install.sh` options |
|------|----------------|-------------------|
| [PHP CLI command](./php-command.mdx) | A Symfony Console app with several commands | Selected by default. `--php-command` also selects it. |
| [PHP CLI script](./php-script.mdx) | A self-contained single-file script | `--php-script`, which also turns off the command app |
| [PHP library](./php-library.mdx) | Classes that other projects install with Composer, with no executable | `--no-php-command --no-php-script` |

Every mode uses the same tooling:

- [Composer](./composer.mdx): the dependencies and scripts in `composer.json`
- [Linting](./linting.mdx): PHP_CodeSniffer, PHPStan and Rector
- [Testing](./testing.mdx): PHPUnit and code coverage

To leave PHP out, pass `--no-php` to `install.sh`.
