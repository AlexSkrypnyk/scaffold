# NodeJS

NodeJS support adds a single-file command-line interface (CLI) script, `nodejs-script`, to your project, with linting and tests already set up. It's on by default. To leave it out, answer `n` to the **Use NodeJS** prompt in `init.sh`, or pass `--no-nodejs`.

Pick the page for your task:

- [NodeJS CLI script](./nodejs-script.mdx): adapt the script and write tests for it
- [Linting](./linting.mdx): check the code with ESLint and Prettier
- [Testing](./testing.mdx): run the tests and collect coverage
- [Release](../ci/release.mdx): attach `nodejs-script` to a GitHub release
