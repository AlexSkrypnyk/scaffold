# NodeJS

NodeJS support adds `nodejs-script`, a single-file command-line interface (CLI) script, to your project. The pages in this section are for developers who work on that script in a project generated from Scaffold.

NodeJS support is on by default. To leave it out, run `install.sh` with `--no-nodejs` or answer `n` to its **Use NodeJS** prompt.

Pick the page for your task:

- [NodeJS CLI script](./nodejs-script.mdx): adapt the script
- [Linting](./linting.mdx): check the code with ESLint and Prettier
- [Testing](./testing.mdx): run and write tests, and measure coverage
- [Release](./release.mdx): publish a version to npm and GitHub
