# Linting

Follow this page to check your shell scripts with ShellCheck and format them with shfmt. Install both tools before you run the commands. The [Test shell workflow](https://github.com/AlexSkrypnyk/scaffold/blob/main/.github/workflows/test-shell.yml) runs both tools in CI, with the same shfmt options.

## Usage

`init.sh` renames the script, by default after your project, such as `acme-app.sh`. Use your script's name in place of `shell-command.sh` in the following commands.

To check the script and the tests, run the following commands in your project root:

```bash
shellcheck shell-command.sh tests/bats/*.bash tests/bats/*.bats
shfmt -i 2 -ci -s -d shell-command.sh tests/bats/*.bash tests/bats/*.bats
```

ShellCheck reports problems in each file. With `-d`, shfmt prints a diff of the formatting changes it would make.

To fix the formatting, run the following command:

```bash
shfmt -i 2 -ci -s -w shell-command.sh tests/bats/*.bash tests/bats/*.bats
```

With `-w`, shfmt writes the formatted result back to each file.

## ShellCheck

[ShellCheck](https://github.com/koalaman/shellcheck) reports warnings and suggestions for Bash and `sh` scripts. To turn off a rule for a whole file, add a `# shellcheck disable=` comment with the rule's code before the file's first command. `shell-command.sh` uses this comment for `SC2162`.

## shfmt

[shfmt](https://github.com/mvdan/sh) is a shell parser, formatter and interpreter. It supports POSIX shell, Bash and mksh.
