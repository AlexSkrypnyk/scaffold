# Shell

Shell support adds `shell-command.sh`, a single-file Bash script template, to your project. The pages in this section are for developers who work on that script in a project generated from Scaffold.

Shell support is on by default. To leave it out, run `install.sh` with `--no-shell` or answer `n` to its **Use Shell** prompt.

Pick the page for your task:

- [Shell CLI command](./shell-command.mdx): rename and adapt the script
- [Linting](./linting.mdx): check the script and its tests with ShellCheck and format them with shfmt
- [Testing](./testing.mdx): run and write tests with BATS, and find the coverage reports
