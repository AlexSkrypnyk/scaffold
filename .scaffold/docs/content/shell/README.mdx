# Shell

Shell support adds a Bash script template to your project, with example tests and linting. It's on by default. To leave it out, answer `n` to the **Use Shell** prompt in `init.sh`, or pass `--no-shell`.

The following pages cover each part:

- [Shell CLI command](./shell-command.mdx): the script template, its filename and how to make it your own
- [Linting](./linting.mdx): check scripts with ShellCheck and format them with shfmt
- [Testing](./testing.mdx): run the tests with BATS and collect coverage
