# Testing

You test your shell script with [BATS](https://github.com/bats-core/bats-core), the Bash Automated Testing System, and CI measures coverage with kcov. This page is for developers who change the shell script or its tests in a project generated from Scaffold. Follow it to run the tests, write your own and find the coverage reports.

## Run the tests

The example tests use [BATS Helpers](https://bats-helpers.drevops.com/), a library that adds assertions, data providers, mocking and step runners to BATS.

To run the tests from your project root:

1. Install BATS and BATS Helpers with npm from [`tests/bats/package.json`](https://github.com/AlexSkrypnyk/scaffold/blob/main/tests/bats/package.json):

   ```bash
   npm ci --prefix tests/bats
   ```

2. Commit your changes to the script, because `shell-command.bats` runs the script from a copy of your last commit.
3. Run every test:

   ```bash
   ./tests/bats/node_modules/.bin/bats tests/bats
   ```

   Confirm that BATS reports no failures. 2 of the example tests call a live joke API, so they fail without network access.

## Write tests

[`shell-command.bats`](https://github.com/AlexSkrypnyk/scaffold/blob/main/tests/bats/shell-command.bats) holds 4 example tests. Each test runs the script with the `tui_run` function from BATS Helpers, which feeds answers to the script's prompts. The tests cover the following cases:

- Answers to the topic prompt and the `Proceed?` question, calling the live joke API
- A topic answer and `SHOULD_PROCEED=y`, so the script skips the `Proceed?` question and calls the live joke API
- A topic answer and `SHOULD_PROCEED=n`, so the script stops
- A topic answer and a mock of the `curl` call, set up with the `steps_run` function from BATS Helpers

`shell-command.bats` loads [`_helper.bash`](https://github.com/AlexSkrypnyk/scaffold/blob/main/tests/bats/_helper.bash), which sets up every test:

- It stops the run unless you start BATS from the project root.
- It loads BATS Helpers.
- It creates a temporary build directory and runs each test inside it.
- It copies your last commit into the build directory when a test file sets `BATS_HELPERS_FIXTURE_EXPORT_CODEBASE_ENABLED=1`, as `shell-command.bats` does.

## Coverage

In CI, the [Test shell workflow](https://github.com/AlexSkrypnyk/scaffold/blob/main/.github/workflows/test-shell.yml) runs the tests under kcov on the `ubuntu-latest` runner to measure coverage. It writes HTML and Cobertura (`cobertura.xml`) reports to `.logs/.coverage-html` and uploads that directory as a build artifact. When the `CODECOV_TOKEN` secret is set, it also uploads the reports to [Codecov](https://codecov.io/).
