# Auto assign PR

The `Auto Author Assign` workflow assigns each pull request to its author. For maintainers of a Scaffold project, this page covers when it runs and how to remove it.

The workflow, `.github/workflows/assign-author.yml`, runs the [`toshimaru/auto-author-assign`](https://github.com/toshimaru/auto-author-assign) action when a pull request is opened or reopened. The action leaves a pull request unchanged when it already has an assignee or a bot opened it.

The `pull_request_target` event starts the workflow, so GitHub runs the workflow file from the base branch. Its token can write to pull requests, even on a pull request from a fork. The workflow checks out no pull request code, so a fork's code never runs with that access.

`install.sh` keeps the workflow by default. To leave it out, answer no to the `install.sh` prompt **Use GitHub PR author auto-assign** or pass `--no-pr-autoassign`. In an existing project, delete `.github/workflows/assign-author.yml`.
