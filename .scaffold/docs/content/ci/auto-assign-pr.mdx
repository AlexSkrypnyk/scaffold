# Auto assign PR

The `Auto Author Assign` workflow in `.github/workflows/assign-author.yml` assigns a pull request to its author. It runs the [`toshimaru/auto-author-assign`](https://github.com/toshimaru/auto-author-assign) action when a pull request is opened or reopened. The action skips pull requests that already have an assignee or that a bot opened.

The `pull_request_target` event triggers the workflow, so GitHub runs your repository's copy of the workflow with write permission on pull requests. That holds for pull requests from forks too.

`init.sh` keeps the workflow by default. To leave it out of a new project, answer no to the `init.sh` prompt **Use GitHub PR author auto-assign**, or pass `--no-pr-autoassign` to `init.sh`. To remove it from an existing project, delete `.github/workflows/assign-author.yml`.
